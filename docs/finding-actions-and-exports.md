# Finding actions and exports

The finding detail's **Create ticket** action builds a draft from the selected persisted scan. It includes the recorded severity, evidence path and line, risk context, migration roadmap action, PQC targets, hybrid mode, and a finding link. It excludes source excerpts, evidence attributes, credentials, and key material. Without an issue integration, one click copies the title and Markdown body; the draft remains visible for manual copying if clipboard access fails.

To enable one-click GitHub Issue creation, provision `QRYPTON_GITHUB_ISSUES_REPO=OWNER/REPO` and a server-only `QRYPTON_GITHUB_ISSUES_TOKEN` with repository Issues write permission. Set `QRYPTON_PUBLIC_URL` to the HTTPS UI origin for absolute finding links. Only Developer and Security Engineer principals can create issues. The server selects and checks the tenant's persisted finding, posts to the fixed `api.github.com` endpoint, and records the returned issue URL so repeat clicks return the existing issue. Viewer and CI Publisher cannot create issues. A failed upstream request shows an error and leaves the copyable draft available. [GitHub's Create an issue API](https://docs.github.com/en/rest/issues/issues) documents the required endpoint and token permission.

CI publishers may add `introduced_finding_ids` and `gate_effect` (`blocks`, `warns`, or `not_evaluated`) to the CI result submission. IDs must exist in the tenant's associated scan. The Developer home provides a copy-ready PR comment with each introduced finding's persisted severity, the explicit gate effect, and an absolute UI link. It does not invent findings or gate decisions when the publisher omits them.

The Reports & CBOM panel previews the selected scan's scope, asset and finding counts, severity breakdown, and export availability from its persisted result. JSON/CSV CBOM and PDF report downloads show a generating state, a success chip, or a clear error. An empty scan is stated explicitly. CBOM exports preserve recorded observation states and provenance. The exporter excludes source excerpts and free-form evidence attributes and permits only known cipher-mode parameters; legacy persisted CBOMs are projected through the same redaction at download time without changing historical stored bytes or risk assessments.
